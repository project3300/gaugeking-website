Race-day flow
1. Enter the Race Control PIN.
2. Paste the Natsoft event page URL when setting/changing the event.
3. Upload a revised driver CSV/TXT if the tracked list changes.
4. Tap SAVE & UPDATE LIVE RESULTS.

After that, automatic polling returns to the event page every 5 minutes, finds the newest published Result link, and keeps earlier captured sessions on the Gauge King results page.
The GitHub credential is stored only in the secure Gauge King backend. Uploaded driver names are saved into the race-results configuration; the source file itself is not stored.
