At a glance

One app. Several ways to see your drive.

Vehicle data, GPS lap timing and video are separate sources. Connect the ones you need; a RaceBox connection does not supply engine RPM, and glasses do not record your Replay Studio telemetry.

01 / Vehicle setup

Start with a trustworthy signal.

In the app: Settings → Set Up My Car

  1. Park, connect your adapter and switch the ignition on as required. Follow your adapter's instructions and use it only with a compatible vehicle.
  2. Open Set Up My Car. Select the appropriate vehicle and connection options for your setup. Connect using Gauge King's adapter controls.
  3. Verify readings before customising. Check that RPM and other available readings respond as expected. A missing channel is not a zero reading.
  4. Choose your gauges and units. Configure your dashboard, warning thresholds and shared Shift Light setup while stationary.

02 / RaceBox Micro

A line. A crossing. Your next lap.

In the app: Settings → Racebox Setup

  1. Connect to RaceBox Micro. Power it on, scan in Racebox Setup and select the unit.
  2. Wait outdoors for usable GPS. Check GPS / timing status. Being Bluetooth-connected alone is not enough.
  3. Set Start / Finish Line. Tap two endpoints on opposite sides of the track. They define one line across the circuit, not separate start and finish locations. Use a line 5–100 metres long and save it.
  4. Tap Start Track Session. Cross the line at at least 10 km/h to start lap 1. The first crossing establishes the driving direction.
  5. Complete a valid lap. It must satisfy the minimum 15 seconds and 100 metres travelled. The first valid completed lap provides a delta reference; faster valid laps replace it.
  6. Stop Track Session when finished. Starting a new track session clears its previous laps. Use Replay Studio separately if you want to retain telemetry for video work.

03 / Meta glasses

Put the essentials in your lens.

In the app: Settings → Meta HUD Setup

  1. Prepare compatible display glasses. Complete the manufacturer's setup and keep the glasses and Meta integration app up to date.
  2. Pair Glasses in Gauge King. Complete Meta's registration flow and return to Gauge King. Registration is separate from connecting the display.
  3. Choose HUD layout. Pick Track Cockpit, Compact, Text or RaceBox. For Track Cockpit, select your three secondary gauges.
  4. Check the data source and units. Connect vehicle telemetry and/or RaceBox for live readings, or use the demo tools while parked.
  5. Tap Connect Display. Confirm the HUD appears and is readable before use. If the SDK interrupts the session, reconnect explicitly.

04 / ENGO & ActiveLook

A focused, lightweight HUD.

In the app: Settings → ENGO HUD Setup

  1. Enable ActiveLook. Power on compatible glasses, then tap Scan for Glasses and select the device.
  2. Confirm the connection. Use Test Display while parked to check the output.
  3. Choose Layout, units and brightness. For lap timing, connect RaceBox and start Gauge King's track session, then use Show RaceBox on ENGO in Racebox Setup.

05 / Replay Studio

Make the drive tell its story.

In the app: Settings → Replay Studio

Replay Studio records telemetry locally. Your camera records video independently. A session holds the telemetry; a project holds a clip, its alignment and your overlay choices.

  1. Prepare live data. Connect your vehicle and RaceBox as needed. For laps, define the line and start a track session in Racebox Setup. Glasses are optional.
  2. Start Session in Replay Studio before driving. Record your camera footage independently. You do not need to import the Gauge King session again.
  3. Stop Session when parked. Open it from Recorded Sessions and create a New Replay Project.
  4. Import Video (Files). For a clip in Photos, share it and choose Save to Files first, then import that copy. Import does not overwrite your original footage.
  5. Choose an overlay in HUD Simulator. Select a Meta layout to reproduce the in-lens graphics with transparent backgrounds. Adjust its size and position.
  6. Align, preview and save. Turn off HUD Demo / Test, enable Show source video, adjust Video offset and check a recognisable event. See the alignment guide below.
  7. Export Video. Keep Gauge King in the foreground until complete, then Share Export. Output is a new file, not a replacement for the source clip.

Want to make a demo video? Enable the app's Demo Mode, start RaceBox Demo Preview if needed, and record a new Replay Studio session. Then use that saved session in a project. Simulated readings retain their demo labels in playback and export. The editor's HUD Demo / Test toggle is only a preview.

Use Replay Studio's recorder for this workflow, not the separate Sessions-tab recorder. Replay reconstructs the HUD from available channels; it is not a capture of actual glasses frames. Missing readings stay missing. Keep acquisition foregrounded; iOS suspension can interrupt recording.

06 / Synchronisation

Same moment. Same frame.

In your replay project: Synchronization — offsets in seconds

All offsets use seconds, to three decimal places: 1.000 is one second, 0.100 is a tenth and 68.000 is one minute eight seconds. Decimal input precision does not guarantee millisecond sensor or video accuracy.

Session time=Video time+Video offset
  1. Start with the individual source offsets at 0. Gauge King's sources share a recording clock. Usually only Video offset needs adjustment.
  2. Find a clear event. Pulling away from stationary is useful: compare visible motion with speed beginning to rise. You can also compare an obvious engine-speed or gear change if recorded.
  3. Calculate Video offset. Subtract the event's position in the video from its telemetry session time. An event at session time 25 s and video time 5 s needs +20.000.
  4. Preview near the video start. With Video offset +30.000, scrub to session time 30 s to see the beginning of the clip. Earlier session times have no video.
  5. Fine-tune and save. Use Play / Pause and − frame / + frame. If telemetry appears too early, decrease Video offset; if too late, increase it. Check another event later, then Save Alignment.
Offset direction cheat sheet
ControlPositive valueNegative value
Video offsetVideo starts later on the session timeline. At a fixed video moment, you see later telemetry.Video starts before session time zero. Early frames may have no telemetry.
Individual source offsetThat source's samples appear later on the session timeline.That source's samples appear earlier on the session timeline.
Worked example / RaceBox timing

Show timing from 1:08 at the start of your video.

If Video offset is +30.000, set racebox-timing to −38.000: 30 − 68 = −38. Video time zero now shows RaceBox timing from source time 68 seconds.

This shifts lap number, lap time and delta only. It does not move GPS speed or OBD. To advance the timing source by an additional 68 seconds instead, use a source offset of −68.000.

One offset corrects a constant timing difference. It does not correct clock drift. If the start aligns but the end does not, check the footage, source timing and recording gaps rather than assuming a single offset can fix everything.

Troubleshooting

A few quick answers.

RaceBox is connected. Why are the lap values blank?

You still need usable GPS, a saved start/finish line, Start Track Session and a valid first crossing. Delta also needs a completed valid reference lap. Check GPS / timing in Racebox Setup.

Why does Demo Mode show RPM but no RaceBox laps?

Vehicle Demo Mode and RaceBox Demo Preview are separate. In Meta HUD Setup or Racebox Setup, start RaceBox Demo Preview as well. Choose the RaceBox layout to see all three timing values.

Why does the replay show a black screen instead of my video?

Turn off HUD Demo / Test and enable Show source video. Confirm a clip is imported and scrub into its time range. With a +30-second Video offset, the clip begins at session time 30 seconds, not zero.

Will saving a layout or offset overwrite my recording?

No. Project edits save layout and alignment separately. Import copies footage, and export creates a new file. Deleting a session is different: after confirmation, it removes that session's local projects and imported clips as well.

Can I record Meta video and a live in-lens HUD at the same time?

This combination has not been verified as a reliable workflow. Test your exact glasses and firmware while parked. Replay Studio can recreate the HUD later from telemetry with independently recorded footage.

Why is gear missing in a Meta replay?

Meta displays measured gear, not an estimated gear presented as measured. If no suitable gear channel was recorded, it remains --. Missing source data cannot be recovered by choosing a different layout.
